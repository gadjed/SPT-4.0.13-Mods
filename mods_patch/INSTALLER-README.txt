SPT 4.0.13 — Mods Pack Installer
================================

1. Copy manage-modpack.cmd AND manage-modpack.ps1 into your SPT root
   (same folder as EscapeFromTarkov.exe / SPT.Server.exe).
2. Run manage-modpack.cmd
3. Menu:
   1 — Auto-update (clean + download latest ModPack from GitHub + install)
   2 — Clean mods only
   3 — Install mods
   4 — Install SVM from official GhostFenixx/svm-csharp release
      (not bundled in ModPack; license forbids redistribution)
   5 — Exit

Internet is required for auto-update / SVM install, and for install when
the ModPack zip is not next to the scripts.

Repo: https://github.com/gadjed/SPT-4.0.13-Mods
ModPack releases: https://github.com/gadjed/SPT-4.0.13-Mods/releases
SVM upstream: https://github.com/GhostFenixx/svm-csharp/releases
