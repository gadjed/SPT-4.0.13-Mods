SPT 4.0.13 - Mods Pack Installer
================================

Unpack manage-modpack.cmd + manage-modpack.ps1 into your SPT game root
(same folder as EscapeFromTarkov.exe; SPT.Server.exe may live in SPT\), then run manage-modpack.cmd.

Nested SPT layout: server mods install/sync to SPT\user\mods.
DanW QuestingBots is removed when QuestingBotsContinuous is present.

Repo: https://github.com/gadjed/SPT-4.0.13-Mods
