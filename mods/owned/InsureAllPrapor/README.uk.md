# Застрахувати все (Прапор)

**Сумісність: SPT 4.0.13**

Клієнтський мод додає кнопку **«Застраховать все»** біля слота шолома на екрані схрону / екіпірування. Один клік страхує екіпірований лутаут у **Прапора** за рублі через ванільний API страховки — без вікна підтвердження.

Розроблено й перевірено на **SPT 4.0.13**.

[Останній реліз](https://github.com/gadjed/Insure-all-prapor-SPT-mod/releases/latest) · [Ліцензія: MIT](LICENSE)

## Можливості

- Кнопка на панелі екіпірування схрону, біля шолома
- Страхує весь придатний одягнений лутаут (зброя, броня, розгрузка/рюкзак/кишені, моди)
- Звичайна платна страховка Прапора (`InsuranceCompanyClass`)
- Без діалогу підтвердження
- Пропускає вже застраховане та те, що не страхується
- Налаштування через F12
- Серверний мод не потрібен

## Встановлення

1. Завантаж `InsureAllPrapor-*.zip` з [Releases](https://github.com/gadjed/Insure-all-prapor-SPT-mod/releases)
2. Розпакуй у **корінь SPT** (тека з `EscapeFromTarkov.exe` / `BepInEx/`)
3. Запусти гру

Шлях у архіві:

```text
BepInEx/plugins/InsureAllPrapor.dll
```

## Налаштування (F12)

| Параметр | Типово | Опис |
|----------|--------|------|
| `Enabled` | `true` | Показувати кнопку |
| `ButtonLabel` | `Застраховать все` | Текст кнопки |
| `Debug` | `false` | Детальний лог |

## Примітки

- Страхується лише **екіпірування PMC**, не сітки схрону
- Потрібно достатньо рублів у схроні
- Сумісно з серверними модами повернення страховки (наприклад Insurance Control)
