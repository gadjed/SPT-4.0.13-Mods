# Defib Ally Revive

Клієнтський мод для **SPT 4.0.13**: оживлення союзників **дефібрилятором з панелі хоткеїв**.

## Як грати

1. Візьми **Portable defibrillator** (`Defib`) у кишені / розвантаження.
2. Перетягни на слот швидкого використання (мод дозволяє прив’язку цього бартерного предмета).
3. Союзник з тим самим `GroupId` (наприклад, Fika) при смертельному уроні падає в **downed**, а не помирає остаточно.
4. Підійди на ~3.5 м і натисни хоткей з дефібрилятором — канал оживлення (5 с). Після успіху дефібрилятор зникає.

## Налаштування (F12)

- **RequireSameGroup** (за замовч. true) — лише напарники з однієї групи
- **AllowSameSide** — також та сама сторона USEC/BEAR (для соло без GroupId вимкни RequireSameGroup і ввімкни це)
- **BleedoutTime** — час до остаточної смерті (90 с)
- **ConsumeDefibrillator** / **FullHealOnRevive**
