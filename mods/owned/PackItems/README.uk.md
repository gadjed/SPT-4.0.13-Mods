# Pack Items

**Сумісність: SPT 4.0.13**

Клієнтський мод додає пункт **Скласти предмети** у контекстне меню контейнера в схроні (ящик з гранатами, хлам, медицина тощо). Підходящі предмети з сітки схрону переносяться у вибраний контейнер, доки перший сумісний предмет уже не вміщується.

## Можливості

- Пункт меню на контейнерах у схроні / інвентарі торговця
- Ураховує фільтри комірок контейнера
- Бере лише предмети **з верхнього рівня** схрону (не з інших кейсів)
- Зупиняється на першому предметі, який не вміщується (без оптимізації розкладки)
- Пропускає закріплені / заблоковані предмети
- Не показується в рейді
- Налаштування через F12
- Серверний мод не потрібен

## Встановлення

Покладіть `PackItems.dll` у `BepInEx/plugins/`.

## Збірка

Див. `References/README.md`, потім:

```bash
dotnet build PackItems.csproj -c Release
```
