---

## English

### Description
Updates flea/handbook prices from a live price database (PvP or PvE mode).

### Settings
(`user/mods/DrakiaXYZ-LiveFleaPrices/config/`)
- **maxIncreaseMult** (10) — cap vs base flea price
- **maxLimiter** (false) — enforce the mult cap when true
- **pvePrices** (false)
- **disablePriceFetching** (false)
- **debug** (false)
- **blacklist.json** — items excluded from updates

### Notes
Install: `user/mods/DrakiaXYZ-LiveFleaPrices/`. Needs network for fetch (falls back to cache).

## Українська

### Опис

(`user/mods/DrakiaXYZ-LiveFleaPrices/config/`)

- **disablePriceFetching** (false)
