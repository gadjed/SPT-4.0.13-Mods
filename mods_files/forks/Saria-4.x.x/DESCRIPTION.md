## English

### Description
Adds custom trader Saria with a rebalanced LL1–4 assort (meds, ammo, gear, etc.), including BlackRock chest rig, SPEAR 6.8 ammo, and Lancer magazines.

### Settings
(`user/mods/Saria/config.json`)
- **RandomizeStockCount** (false) — keep large stock (999999); set true to randomize / deplete offers
- **RemoveMoneyLlRequirements** (true)
- **RemoveLevelLlRequirements** (true)
- Avatar/preset assets under `Assets/`

### Notes
Install: `user/mods/Saria/`. Replaces older Saria folders if present. After ModPack updates, re-check `config.json` — pack may overwrite it.

## Українська

### Опис
Додає торговця Saria з перебалансованим асортиментом LL1–4 (меди, патрони, спорядження тощо), включно з розгрузкою BlackRock, набоями 6.8 і магазинами Lancer для SPEAR.

### Налаштування
(`user/mods/Saria/config.json`)
- **RandomizeStockCount** (false) — велика кількість (999999); true = рандом / дефіцит
- **RemoveMoneyLlRequirements** (true)
- **RemoveLevelLlRequirements** (true)
- Аватари/пресети в `Assets/`

### Примітки
Встановлення: `user/mods/Saria/`. Замінює старі теки Saria, якщо були. Після оновлення ModPack перевір `config.json` — пак може його перезаписати.
