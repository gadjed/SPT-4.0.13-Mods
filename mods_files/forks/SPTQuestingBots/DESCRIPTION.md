## English

### Description
Fork of DanW Questing Bots with continuous map population (PMC top-up + scav reinforcements). Replaces standalone Scav Population and stock Questing Bots.

### Notes
Requires BigBrain and Waypoints. Install into SPT game root (`BepInEx/plugins/QuestingBotsContinuous/` + `SPT/user/mods/...`).
