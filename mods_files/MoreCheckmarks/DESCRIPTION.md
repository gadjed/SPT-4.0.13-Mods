## English

### Description
Colored checkmarks and tooltips on items needed for hideout, quests, wishlist, barters, and crafts.

### Settings
**Client (F12):** show/hide quest/hideout/wishlist/barter/craft marks; FIR rules; priority integers; colors.
**Server:** hide inactive event quests; excluded quest IDs.

### Notes
Install: `BepInEx/plugins/MoreCheckmarks/` + `user/mods/MoreCheckmarksBackend/`. Pairs well with UI Fixes.

## Українська

### Опис
Кольорові галочки й підказки на предметах для схрону, квестів, вішліста, бартерів і крафту.

### Налаштування
**Клієнт (F12):** показувати/ховати галочки квестів/схрону/вішліста/бартерів/крафту; правила FIR; пріоритети; кольори.
**Сервер:** ховати неактивні івент-квести; excluded quest IDs.

### Примітки
Встановлення: `BepInEx/plugins/MoreCheckmarks/` + `user/mods/MoreCheckmarksBackend/`. Добре з UI Fixes.
