## English

### Description
Unified medical toolkit: **Auto Med Hotkeys** + **Defib Ally Revive** + **Med Rebalance** (continuous healing / surgery timing / defibrillator resource) in one mod with F12 toggles.

Replaces standalone `AutoMedHotkeys`, `DefibAllyRevive`, and `MedRebalance` — remove those before installing.

### Install
```text
BepInEx/plugins/MedSuite.Client.dll
SPT/user/mods/MedSuite/MedSuite.dll
SPT/user/mods/MedSuite/config.json
```
