# Quick Search

| | |
|---|---|
| **Version** | v1.0.0 |

| **Target** | SPT 4.0.13 |

---

## English

### Description
Speeds up searching containers and corpses by a configurable multiplier.

### Settings
(`BepInEx/config/gadjed.quicksearch.cfg` / F12)
- **SearchSpeedMultiplier** (default: 3)

### Notes
Install: `BepInEx/plugins/QuickSearch.dll`.

---
