## English

### Description
Successful **RSP-30 Yellow** (once per raid) curses scavs (teleport ring + hunt), optional Tagilla / cultists, then drops a forced high-value SUPPLY airdrop after a delay.

### Notes
**SPT 4.0.13 only (net9).** Install: `SPT/user/mods/YellowFlareCurse/` + `BepInEx/plugins/YellowFlareCurse.Client.dll`.

---

## Українська

### Опис
Успішне **RSP-30 Yellow** (раз за рейд) проклинає диких (кільце телепорту + полювання), опційно Tagilla / сектанти, потім форсований цінний SUPPLY аірдроп після затримки.

### Примітки
**Лише SPT 4.0.13 (net9).** Встановлення: `SPT/user/mods/YellowFlareCurse/` + `BepInEx/plugins/YellowFlareCurse.Client.dll`.
