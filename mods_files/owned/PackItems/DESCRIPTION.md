# Pack Items

| | |
|---|---|
| **Version** | v1.0.0 |
| **Type** | Client / Клієнт |
| **Source** | https://github.com/gadjed/Pack-items-SPT-mod |
| **Target** | SPT 4.0.13 |

---

## English

### Description
Adds **Скласти предмети** to the right-click context menu on stash containers (grenade box, junk box, meds case, etc.). Compatible loose items from the stash grid are moved into the selected container until the first item that no longer fits.

### Settings
(`BepInEx/config/gadjed.packitems.cfg` / F12)
- **Enabled** (default: true)
- **MenuLabel** (default: Скласти предмети)
- **Debug** (default: false)

### Notes
Install: `BepInEx/plugins/PackItems.dll`.
Top-level stash items only; skips pinned/locked; not shown in raid. No server mod required.

---

## Українська

### Опис
Додає пункт **«Скласти предмети»** у контекстне меню контейнера в схроні (ящик з гранатами, хлам, медицина тощо). Підходящі предмети з сітки схрону переносяться у вибраний контейнер, доки перший сумісний предмет уже не вміщується.

### Налаштування
(`BepInEx/config/gadjed.packitems.cfg` / F12)
- **Enabled** (типово: true)
- **MenuLabel** (типово: Скласти предмети)
- **Debug** (типово: false)

### Примітки
Встановлення: `BepInEx/plugins/PackItems.dll`.
Лише предмети верхнього рівня схрону; пропускає закріплені/заблоковані; не в рейді. Серверний мод не потрібен.
