# Auto Med Hotkeys

| | |
|---|---|
| **Version** | v1.0.3 |
| **Type** | Client / Клієнт |
| **Source** | https://github.com/gadjed/Auto-med-hotkeys-SPT-mod |
| **Target** | SPT 4.0.13 only |

---

## English

### Description
Automatically binds medical items to quick-use slots **4 / 5 / 6** when they are in pockets or tactical rig — both in stash and in raid.

| Slot | Items |
|------|--------|
| **4** | Medkits (AI-2, Car, Salewa, IFAK, AFAK, Grizzly, …) |
| **5** | Esmarch, CAT, CALOK-B, Zagustin |
| **6** | Bandages |

### Settings
(`BepInEx/config/gadjed.automedhotkeys.cfg` / F12)
- **Enabled** (default: true)
- **OverwriteExisting** (default: true)
- **Debug** (default: false)

### Notes
Install: `BepInEx/plugins/AutoMedHotkeys.dll`. No server mod. Surgical kits / splints are not auto-bound.

## Українська

### Опис
Автоматично прив’язує медикаменти до слотів швидкого використання **4 / 5 / 6**, коли вони в кишенях або розвантаженні — і в схроні, і в рейді.

| Слот | Предмети |
|------|----------|
| **4** | Аптечки |
| **5** | Есмарх, CAT, CALOK-B, Загустін |
| **6** | Бинти |

### Налаштування
(`BepInEx/config/gadjed.automedhotkeys.cfg` / F12)
- **Enabled** (за замовч.: true)
- **OverwriteExisting** (за замовч.: true)
- **Debug** (за замовч.: false)

### Примітки
Встановлення: `BepInEx/plugins/AutoMedHotkeys.dll`. Серверний мод не потрібен.
