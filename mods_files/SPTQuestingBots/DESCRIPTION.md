## English

### Description
Bots pursue quests/objectives; continuous PMC top-up and scav reinforcement waves (former Scav Population features are merged in).

### Settings
(`user/mods/QuestingBotsContinuous/config.json` + client quest JSONs)
- **enabled**
- Large **questing** / **bot_spawns** trees (roles, hostility, spawn counts)
- **continuous_population** — PMC top-up interval (~45s after warmup), scav waves (~180s), map skip list (lab/labyrinth/hideout)
- PMC group size weights (biased toward 2–4)

### Notes
Install: `user/mods/QuestingBotsContinuous/` + `BepInEx/plugins/QuestingBotsContinuous/`. Needs BigBrain ≥1.4.0 + Waypoints. Do **not** stack with DanW QuestingBots or standalone Scav Population.

## Українська

### Опис
Боти виконують квести/цілі; безперервний доспавн PMC і хвилі скавів (функції колишнього Scav Population уже всередині).

### Налаштування
(`user/mods/QuestingBotsContinuous/config.json` + клієнтські quest JSON)
- **enabled**
- Великі дерева **questing** / **bot_spawns**
- **continuous_population** — доспавн PMC (~45 с після прогріву), хвилі скавів (~180 с), пропуск lab/labyrinth/hideout
- Ваги розміру груп PMC (зсув до 2–4)

### Примітки
Встановлення: `user/mods/QuestingBotsContinuous/` + `BepInEx/plugins/QuestingBotsContinuous/`. Потрібні BigBrain ≥1.4.0 + Waypoints. **Не** ставте разом з DanW QuestingBots або окремим Scav Population.
