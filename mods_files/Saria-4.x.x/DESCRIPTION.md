## English

### Description
Adds custom trader Saria with a rebalanced LL1–4 assort (meds, ammo, gear, etc.).

### Settings
(`user/mods/Saria/config.json`)
- **RandomizeStockCount** (true)
- **RemoveMoneyLlRequirements** (true)
- **RemoveLevelLlRequirements** (false)
- Avatar/preset assets under `Assets/`

### Notes
Install: `user/mods/Saria/`. Replaces older Saria folders if present.
