## English

### Description
API for adding custom bot types (WildSpawnType + server bot data). Not a full custom-bot pack by itself.

### Settings
(`MoreBotsServer/config.jsonc`)
- **enableCallLogs** (false)
- **increaseBotCapAmount** (5)

### Notes
Install: `BepInEx/patchers/MoreBotsPrepatch.dll` + `BepInEx/plugins/MoreBotsAPI/` + `user/mods/MoreBotsServer/`. Enum conflicts can break the game.

## Українська

### Опис
API для кастомних типів ботів (WildSpawnType + серверні дані). Сам по собі не додає готових фракцій/босів.

### Налаштування
(`MoreBotsServer/config.jsonc`)
- **enableCallLogs** (false)
- **increaseBotCapAmount** (5)

### Примітки
Встановлення: `BepInEx/patchers/MoreBotsPrepatch.dll` + `BepInEx/plugins/MoreBotsAPI/` + `user/mods/MoreBotsServer/`. Конфлікти enum можуть зламати гру.
