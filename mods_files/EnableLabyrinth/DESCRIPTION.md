# Enable Labyrinth

| | |
|---|---|
| **Version** | 1.0.2 |
| **Type** | Client + server / Клієнт + сервер |
| **Source** | https://github.com/acidphantasm/enablelabyrinth-csharp |
| **Target** | SPT 4.0.13 |

---

## English

### Description
Enables The Labyrinth as a playable map: optional keycard removal, scav entry from the map screen, PMC exfil timing tweaks, and secret-exfil key guarantee.

### Settings
(`user/mods/acidphantasm-enablelabyrinth/config.json`)
- **ChangePmcExfilTimers** (true)
- **PrimaryPmcExfilTimer** — ExfiltrationTime 15; ElapsedSecondsBeforeAvailable 600
- **GuaranteeSecretExfilKey** (true)
- **RemoveKeycardRequirement** (true)
- **AllowScavEntryToLabyrinthFromMap** (true)
- Web config UI settings under ConfigAppSettings

### Notes
Install: `BepInEx/plugins/acidphantasm-enablelabyrinth/` + `user/mods/acidphantasm-enablelabyrinth/`.

## Українська

### Опис
Робить The Labyrinth ігровою локацією: опційно без ключ-карти, вхід скавами з карти, правки таймерів екстракту PMC і гарантія ключа для секретного екстракту.

### Налаштування
(`user/mods/acidphantasm-enablelabyrinth/config.json`)
- **ChangePmcExfilTimers** (true)
- **PrimaryPmcExfilTimer** — ExfiltrationTime 15; ElapsedSecondsBeforeAvailable 600
- **GuaranteeSecretExfilKey** (true)
- **RemoveKeycardRequirement** (true)
- **AllowScavEntryToLabyrinthFromMap** (true)
- Також веб-конфіг (ConfigAppSettings)

### Примітки
Встановлення: `BepInEx/plugins/acidphantasm-enablelabyrinth/` + `user/mods/acidphantasm-enablelabyrinth/`.
