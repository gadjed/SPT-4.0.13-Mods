## English

### Description
Client-side multiplayer for SPT (networking, replication, headless support).

### Settings
Configured in-game / via BepInEx Fika settings (no single small config.json). Match host settings for NAT/relay as needed.

### Notes
Install: `BepInEx/plugins/Fika/`. Requires matching **Fika-Server**. This pack pairs client 2.3.9 with server 2.3.5. Windows only.

---

## Українська

### Опис
Клієнтська частина мультиплеєра SPT (мережа, реплікація, headless).

### Налаштування
Налаштування в грі / через BepInEx Fika. Узгодьте NAT/relay з хостом.

### Примітки
Встановлення: `BepInEx/plugins/Fika/`. Потрібен відповідний **Fika-Server**. У паку: клієнт 2.3.9 + сервер 2.3.5. Лише Windows.
