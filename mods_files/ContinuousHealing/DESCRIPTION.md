---

## English

### Description
Continues healing across body parts instead of stopping after a single limb. Useful with Fast Surgery so CMS/splints stay short while you heal everything in one go.

### Settings
- **Heal Limbs** (F12, default: on) — continue healing other limbs after the first.
- **Heal Delay** (0–5, default: 0) — delay between limb heals (vanilla ~2s).
- **Reset Animations** (default: on) — reset heal animations between limbs.

### Notes
Install: `BepInEx/plugins/ContinuousHealing/`. Pair with Fast Surgery.

## Українська

### Опис
Продовжує лікування по всіх частинах тіла замість зупинки після однієї кінцівки. Добре поєднується з Fast Surgery: короткий час CMS/шин + лікування всього за раз.

### Налаштування
- **Heal Limbs** (F12, типово: увімк.) — продовжувати лікування інших кінцівок.
- **Heal Delay** (0–5, типово: 0) — пауза між кінцівками (ваніль ~2 с).
- **Reset Animations** (типово: увімк.) — скидати анімацію між кінцівками.

### Примітки
Встановлення: `BepInEx/plugins/ContinuousHealing/`. Краще разом із Fast Surgery.
