---

## English

### Description
Using an RSP-30 Yellow (once per raid) teleports eligible scav/PMC AI near you, allies them against players only, then triggers a high-value airdrop after a delay.

### Settings
**Server** (`user/mods/YellowFlareCurse/config.json`): Enabled; AirdropDelaySeconds (600); ForcedLoot stacks.
**Client (F12):** Enabled; AirdropDelaySeconds; ShowCountdown; IncludePlayerGroup; TeleportBotsNearPlayer; TeleportMin/MaxRadius; AiAlliance; Debug.

### Notes
Install: `user/mods/YellowFlareCurse/` + `BepInEx/plugins/YellowFlareCurse.Client.dll`. Needs maps with airdrop points. SAIN / QuestingBots optional bridges.

## Українська

### Опис
Успішне використання RSP-30 Yellow (раз за рейд) телепортує скавів/PMC поруч, блокує їхні бої між собою (полюють лише на гравців) і через затримку викликає аірдроп із цінним лутом.

### Налаштування
**Сервер** (`user/mods/YellowFlareCurse/config.json`): Enabled; AirdropDelaySeconds (600); ForcedLoot.
**Клієнт (F12):** Enabled; AirdropDelaySeconds; ShowCountdown; IncludePlayerGroup; TeleportBotsNearPlayer; TeleportMin/MaxRadius; AiAlliance; Debug.

### Примітки
Встановлення: `user/mods/YellowFlareCurse/` + `BepInEx/plugins/YellowFlareCurse.Client.dll`. Потрібні карти з точками аірдропу. SAIN / QuestingBots опційно.
