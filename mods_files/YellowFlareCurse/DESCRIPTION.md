---

## English

### Description
Using an RSP-30 Yellow (once per raid) curses nearby scavs/PMCs, then triggers a high-value airdrop after a delay.

### Settings
**Server** (`user/mods/YellowFlareCurse/config.json`): Enabled; AirdropDelaySeconds (600); ForcedLoot stacks.
**Client (F12):** Enabled; AirdropDelaySeconds (600); ShowCountdown (true); IncludePlayerGroup (true); Debug (false).

### Notes
Install: `user/mods/YellowFlareCurse/` + `BepInEx/plugins/YellowFlareCurse.Client.dll`. Needs maps with airdrop points. SAIN optional for harder cursed fights.

## Українська

### Опис
Успішне використання RSP-30 Yellow (раз за рейд) проклинає сусідніх скавів/PMC і через затримку викликає аірдроп із цінним лутом.

### Налаштування
**Сервер** (`user/mods/YellowFlareCurse/config.json`): Enabled; AirdropDelaySeconds (600); ForcedLoot.
**Клієнт (F12):** Enabled; AirdropDelaySeconds (600); ShowCountdown (true); IncludePlayerGroup (true); Debug (false).

### Примітки
Встановлення: `user/mods/YellowFlareCurse/` + `BepInEx/plugins/YellowFlareCurse.Client.dll`. Потрібні карти з точками аірдропу. SAIN опційно для жорсткіших боїв із cursed.
